## What these numbers are — and are not

- **They are keyword scores, not live accounting accuracy.** An answer scored
  1 if it contained every required keyword/phrase from the question's `must`
  list (`notebooks/phase1_tally_train.ipynb`, `score()`), 0 otherwise.
  Keyword presence is a weak proxy for a correct, usable answer.
- **Synthetic-data limits apply.** Training Q&A pairs were generated by a
  teacher model (Qwen2.5-3B-Instruct) grounded in scraped Tally help passages,
  then filtered for grounding, length, and test-question leakage. The test
  set is 64 hand-written-style questions. Neither is a representative sample
  of real accountant queries.
- **The fine-tuned Phase 1 model artifact is missing.** Phase 1 expected its
  outputs in a Drive `Tally/out/` folder; that folder was absent when the
  Drive folder was inspected 2026-10-15. The merged model was not recovered.
  Do not treat these scores as reproducible from this repo alone.

## Excluded

`chunks.jsonl` (1,233 scraped Tally help passages) is **not published** —
third-party scraped help text. The notebook still references it as its
training-data source; re-running Stage A requires re-collecting that corpus
yourself.
